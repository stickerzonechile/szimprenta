# Stickerzone Imprenta Digital

Calculadora interactiva de stickers con galería de diseños y cotización en tiempo real.

## 🚀 Deploy Rápido en Vercel (60 segundos)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/stickerzonechile/szimprenta)

### Pasos:
1. Haz clic en el botón **Deploy** arriba
2. Elige tu cuenta de GitHub
3. Vercel clonará automáticamente
4. **¡Listo en 2-3 minutos!** 🎉

Tu URL será: `https://szimprenta-[random].vercel.app`

✅ Cotizador en tiempo real
